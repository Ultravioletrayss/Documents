## 一、与通用策略的核心区别

| 维度 | 通用做市策略 | 增强做市策略 |
|------|------------|------------|

> **一句话总结**：通用版是"基础自动挡"，增强版是"智能手自一体"，能根据市场状态自动切换档位、调整报价、累积对冲。

## 三、模块一：策略逻辑详解

### 3.1 双轨定价系统

#### ① 跟盘报价策略（公式定价，继承通用版）

| 设置项 | 说明 |
|--------|------|
| **基准价模式** | 单基准价（买卖共用）/ 双基准价（买卖分别设置） |
| **公式编辑** | 支持P（标的价格）、A/B（其他合约）、四则运算、函数 |

> 例：`(P+A+B)/3` = 最新价、买一价、卖一价的平均值

#### ② 档位报价策略（新增，锚定市场盘口）

**核心思想**：不自己算基准价，而是**看市场上其他做市商挂在哪里**，跟随他们的档位定价。

| 档位模式 | 买基准价怎么定 | 卖基准价怎么定 |
|---------|--------------|--------------|
| **中间价档位** | 买盘中间档位的挂单价格 | 卖盘中间档位的挂单价格 |
| **中间量档位** | 买盘挂单量平均值的对应档位价格 | 卖盘挂单量平均值的对应档位价格 |
| **自定义档位量** | 买盘累计挂单量达到X手的档位价格 | 卖盘累计挂单量达到X手的档位价格 |

**圆整方案**（中间价档位特有）：
- 偶数档时取中间两档均价，再按方向圆整
- **买方向**：向上圆整（如1.025→1.03）
- **卖方向**：向下圆整（如1.025→1.02）

> **通俗理解**：跟盘是自己算价格；档位报价是"看别人挂在哪里，我跟着挂"，更适合新手做市或流动性依赖型策略。

**关键设置**：
- **剔除本方报价**：计算档位时把自己的挂单剔除，避免"自嗨"（自己挂买一，然后按买一算基准价，永远追着自己跑）
- **档位不存在时递延盘口计算**：5档→4档→3档→2档→1档→对方1档→最新价→昨收，逐级降级取数

---

### 3.2 条件单系统（增强版灵魂）

**设计公式**：`策略 = 条件 + 操作`

| 要素 | 说明 |
|------|------|
| **条件** | 因子 + 逻辑判断（支持 `> < = >= <= & \| ()`） |
| **因子** | 当前时间、盘口价差、买一/卖一、最新价、买卖基准价、盘口价格、涨跌幅等 |
| **操作** | 三种：①额外偏移 ②重设报价 ③暂停报价 |

**三种操作详解**：

| 操作 | 效果 | 应用场景 |
|------|------|---------|
| **额外偏移** | 在原有基准价+偏移量基础上，**再加一层偏移** | 市场波动大时，主动拉大价差保护自己 |
| **重设报价** | **完全替换**原有报价参数（基准价、档位、数量全改） | 行情剧变时，切换成另一套报价方案 |
| **暂停报价** | 撤回所有委托，暂停N秒，期间只监控不报价 | 极端行情避险 |

**优先级规则**：
- 多条件时**按顺序判断**，满足一个即执行，后续条件不再判断
- 支持**上下拖拽改变顺序**

> **通俗理解**：条件单就是"如果…就…"的自动化规则。比如"如果盘口价差>0.5，就把买卖各偏移0.1，拉大价差"；"如果涨跌幅>3%，就暂停报价60秒"。

---

### 3.3 报价更新顺序（重要）

每一轮行情刷新时，策略按以下顺序决策：

```
Step 1: 检查是否有条件单满足？
        ├── 满足 → 执行对应操作（额外偏移/重设报价/暂停报价）
        └── 不满足 → 进入Step 2
        
Step 2: 检查基础报价是否有档位触发容忍度？
        ├── 触发 → 更新该档位报价
        └── 未触发 → 维持现状
```

> **关键**：条件单**优先于**基础容忍度更新。条件单是"主动策略"，容忍度是"被动维护"。

---

### 3.4 部成处理（新增，精细化成交管理）

通用版是"成交即撤单重报"，增强版增加了**部成（部分成交）的灵活处理**：

| 场景 | 选项 | 行为 |
|------|------|------|
| **该档位发生部分成交** | **不想成交** | 立即撤销该档位**剩余挂单**，且可设置N秒内**不再报单** |
| | **想成交** | 剩余挂单**不做处理**，继续维持等待成交 |
| **该档位发生全部成交** | 统一处理 | 继续判断：是否满足条件单更新？基础报价是否触发容忍度？ |

> **通俗理解**：部成时如果你"不想成交"，说明这单是被对手"偷袭"了，赶紧撤掉剩下的，别继续吃亏；如果"想成交"，就留着等继续成。

### 3.5 对冲逻辑（重大变化：从逐笔到净敞口）

| 维度 | 通用策略 | 增强策略 |
|------|---------|---------|
| **触发方式** | 逐笔成交即对冲 | **净成交量/净成交金额达到阈值**才对冲 |
| **对冲数量** | 原成交手数 | 净买入量/对冲系数/报单价格 或 净买入额/对冲系数/合约乘数/报单价格 |
| **对冲类型** | 仅成交后立即对冲 | 新增**定时器对冲**（按秒采集累积对冲） |

**对冲委托数量计算公式**：

| 类型 | 公式 |
|------|------|
| 净买入量对冲 | `委托数量 = 净买入量 / 对冲系数 / 报单价格` |
| 净买入额对冲 | `委托数量 = 净买入额 / 对冲系数 / 合约乘数 / 报单价格` |
| 净卖出量对冲 | `委托数量 = 净卖出量 / 对冲系数 / 报单价格` |
| 净卖出额对冲 | `委托数量 = 净卖出额 / 对冲系数 / 合约乘数 / 报单价格` |

**对冲系数**：用于**非100%对冲**或**跨合约对冲**时的手数换算。比如用TL对冲TS，由于合约价值不同，需要系数调整。

> **通俗理解**：通用版是"每成交一笔立刻对冲"，增强版是"攒够一批再对冲"，减少对冲频率和交易成本，适合大额做市商。

### 4.2 价格保护（新增，防"抢最优"）

**问题**：如果算出的委托价**优于市场最优价**（买价>市场买一，或卖价<市场卖一），会挂在最优档位，容易被频繁成交，风险大。

**解决**：勾选价格保护后，强制按偏移量调整：

```
买价格保护：买价 = 买一价 + 偏移量（一般设为负值，下调）
卖价格保护：卖价 = 卖一价 + 偏移量（一般设为正值，上调）
```

> **效果**：确保自己的报价**不优于市场最优**，躲在后面"跟跑"而不是"领跑"。

---

### 4.3 价格笼子 / 数量笼子 / 报单控制

#### ① 价格笼子

| 设置项 | 说明 |
|--------|------|
| 偏移模式 | 按价格 / 按比例 |
| 笼子边界 | 基准价±偏移量 或 基准价×(1±偏移%) |
| 触发行为 | 价格超出笼子 → **撤单暂停报价**，持续监控，满足条件后恢复 |

#### ② 数量笼子（新增，多维度监控）

| 监控维度 | 控制范围 | 说明 |
|---------|---------|------|
| **监控范围** | 当次策略 / 当日策略（含之前停止过的）/ 当日全部（含手工） | 防止日内累积过量 |
| **成交量** | 净买量 / 净卖量 | 分别控制 |
| **成交额** | 净买额 / 净卖额 | 分别控制 |
| **持仓数量** | 当前持仓上下限 | 实时持仓监控 |
| **持仓金额** | 当前持仓金额上下限 | 实时金额监控 |

> **触发行为**：超出数量笼子 → **策略停止**（非暂停，需手动重启）

#### ③ 报单控制（新增，时间维度风控）

| 设置项 | 说明 |
|--------|------|
| 时间范围 | 至少一个行情间隔以上 |
| 风控操作 | 策略暂停（满足条件自动恢复）/ 策略停止（需手动重启） |
| 阈值字段 | 一段时间内的报单数量/金额、成交数量/金额、标的涨跌幅绝对值、新增净持仓、单边成交数量 |

**涨跌幅绝对值计算步骤**：
1. 找最低价p1（时间t1）和最高价p2（时间t2）
2. 若t2>t1（后涨到高）：判断 `p2/p1 - 1` 是否超阈值
3. 若t2<t1（先涨后跌）：判断 `|p1/p2 - 1|` 是否超阈值

### 4.4 跟盘交易设置（新增，应对复杂交易场景）

| 设置项 | 说明 |
|--------|------|
| **自动开平底仓设置** | 多/空单分别设底仓数量。可用量≤底仓→一律开仓；可用量>底仓→才启动自动开平 |
| **委托响应设置** | 超过X秒未收到确认→策略停止（仅支持合笔顶单） |
| **交易模式** | **全撤再报**：先撤单，等全部撤单确认后再报单（防重复挂单） |
| **废单响应** | 策略停止（超N次废单停）/ 忽略（继续运行） |
| **撤废响应** | 忽略（假设已撤成）/ 重试（X次Y秒间隔，失败则停） |
| **部成响应** | 立即撤余单+N秒不再报单 / 等待全部成交（维持余单） |
| **行情响应** | 处理**委托和行情乱序**问题（见下文） |

---

### 4.5 行情响应机制（新增，解决技术乱序）

**问题**：网络延迟可能导致**先收到成交消息，后收到行情消息**。策略依赖行情触发，如果行情未到，会误以为委托仍在盘中。

**解决**：执行行情响应后，重新根据**当前委托表 + 最近一次行情信息**计算本方量，得到正确的本放委托量，再触发委托/撤单操作。

> **通俗理解**：就像快递先到了但物流信息还没更新，系统会"刷新一下"确保状态同步。

## 五、模块三：对冲策略（独立完整模块）

### 5.1 对冲参数

| 参数 | 说明 |
|------|------|
| 买入对冲/卖出对冲 | 勾选启用 |
| 净买入量/净卖出量 | 买卖轧差后的净成交量达到阈值触发 |
| 净买入额/净卖出额 | 买卖轧差后的净成交额达到阈值触发 |
| 对冲标的 | 原合约或其他期货合约 |
| 对冲系数 | 非100%对冲或跨合约时的手数换算系数 |
| 买卖方向 | 买入对冲默认卖出，卖出对冲默认买入 |
| 价格类型 | 对冲委托价格的基准价来源 |
| 价格偏移 | 在基准价基础上±若干跳 |

### 5.2 对冲风控

- **价格笼子**：同做市端，超出后撤单暂停，满足后恢复
- **涨跌幅笼子**：委托价格需在行情涨跌幅范围内才通过

### 5.3 交易设置

| 设置项 | 说明 |
|--------|------|
| 废单响应 | 对冲单废单是否停策略 / 忽略继续 |
| 撤补响应 | 撤补间隔 / 撤补次数 / 撤补最终失败处理（回补/不回补） |
| 跟踪类型 | 自动 / 手工+自动（统计范围不同） |
| 撤单选项 | 策略自动停止时，是否撤对冲单 |
| **对冲类型** | **定时器对冲**（按秒采集累积）/ **成交后立即对冲** |

## 七、一页纸速查：增强版 vs 通用版

| 你想实现 | 通用版能做到？ | 增强版怎么做 |
|---------|-------------|------------|
| 根据盘口档位自动定价 | ❌ | 用**档位报价策略** |
| 行情波动大时自动拉大价差 | ❌ | 用**条件单→额外偏移** |
| 极端行情自动暂停报价 | ❌ | 用**条件单→暂停报价** |
| 部分成交后不想继续成交 | ❌ | 用**部成响应→立即撤余单** |
| 攒够一批再对冲，减少成本 | ❌ | 设**净买入量阈值**+**定时器对冲** |
| 防止自己的单挂在最优档 | ❌ | 用**价格保护** |
| 控制日内累计成交量 | ❌ | 用**数量笼子**（多维度监控） |
| 处理网络乱序导致的委托状态错误 | ❌ | 用**行情响应** |
| 跨合约对冲时手数换算 | ❌ | 用**对冲系数** |
| 策略优先级管理防自成交 | ❌ | 用**优先级设置** |
