# 做市策略里非常关键的“行情深度”问题

核心区别：

| 交易所       | 普通CTP常见能看到的盘口   |
| --------- | --------------- |
| 上海期货交易所   | 买5卖5（Level2 风格） |
| 郑州商品交易所   | 很多情况下只有买1卖1     |
| 大连商品交易所   | 常常只有1档          |
| 中国金融期货交易所 | 普通接口通常也是1档      |
| 广州期货交易所   | 一般也不完整          |

---

# 一、为什么上期所特殊？

因为上期所 historically（历史上）：

# 对普通CTP就开放了5档行情

例如：

```text
bid1 bid2 bid3 bid4 bid5
ask1 ask2 ask3 ask4 ask5
```

你可以直接看到：

```text
盘口厚度
挂单量
队列结构
```

---

# 二、其他交易所很多时候只有：

```text
bid1
ask1
```

也就是：

# 最优一档

例如：

```text
买一：100
卖一：101
```

但：

```text
买二是多少？
买三是多少？
```

你不知道。

---

# 三、为什么做市特别依赖5档？

因为做市本质是：

# 研究 Order Book（订单簿）

不仅是：

```text
现在价格多少
```

更重要是：

```text
哪里挂单厚
哪里挂单薄
盘口是否失衡
队列是否变化
```

---

# 四、举个真实例子

如果你只能看到：

```text
bid1 = 100
ask1 = 101
```

你根本不知道：

```text
买一后面还有多少单
卖一后面还有多少单
```

---

但如果你能看到：

```text
买1：100  500手
买2：99   2000手
买3：98   5000手

卖1：101  100手
卖2：102  50手
卖3：103  20手
```

你会发现：

# 买盘很厚

市场可能偏强。

---

# 五、做市策略会直接用到5档

例如：

---

## 1. mid 计算更稳定

简单版：

```text
mid = (bid1 + ask1)/2
```

高级版：

# 加权 mid

例如：

```text
weighted_mid
```

会考虑：

```text
bid1_volume
ask1_volume
bid2_volume
ask2_volume
```

---

## 2. 判断盘口失衡

例如：

```text
买盘总量 >> 卖盘总量
```

说明：

```text
市场可能向上
```

于是：

* 买单挂近一点
* 卖单挂远一点

---

## 3. 判断是否容易被打穿

如果：

```text
卖盘只有几手
```

你知道：

```text
价格容易瞬间上跳
```

