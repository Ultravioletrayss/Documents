对冲的核心目的只有一个：

> **做市商不想赌方向，只想赚价差。成交后对冲，是为了把“价格涨跌风险”尽快关掉。**

---

比如你挂了双边单：

```text
买单：100.00
卖单：100.04
```

理想情况是：

```text
别人卖给你，你 100.00 买入
然后别人又来买，你 100.04 卖出
你赚 0.04
```

但现实里不一定这么顺。

---

# 情况一：买单成交了，但卖单没成交

你在 100.00 买入了。

现在你手里有多头仓位。

如果价格马上跌到：

```text
99.90
```

你就亏了：

```text
100.00 - 99.90 = 0.10
```

这时候你原本想赚的价差可能只有：

```text
0.04
```

结果市场一跌，价差没赚到，反而亏更多。

所以买单成交后，系统会想办法尽快卖出，把仓位关掉。

这就是对冲。

```text
买单成交
↓
你持有多头风险
↓
马上卖出对冲
↓
减少价格下跌风险
```

---

# 情况二：卖单成交了，但买单没成交

你在 100.04 卖出了。

现在你手里是空头仓位。

如果价格马上涨到：

```text
100.20
```

你就亏了：

```text
100.20 - 100.04 = 0.16
```

所以卖单成交后，系统会尽快买回来，把空头风险关掉。

```text
卖单成交
↓
你持有空头风险
↓
马上买入对冲
↓
减少价格上涨风险
```

---

# 用一句话理解

做市商挂双边单，不是因为它真的想持仓。

它只是想：

```text
低价买进
高价卖出
赚中间差价
```

但是一边成交后，另一边未必马上成交。

所以它会短暂暴露在市场方向里。

这个暴露就叫：

```text
库存风险 / 持仓风险 / Delta 风险
```

对冲就是把这个风险尽快处理掉。

---

# 举个完整例子

你挂：

```text
买单：100.00
卖单：100.04
```

别人先打到你的买单：

```text
你 100.00 买入 1 手
```

现在你希望卖出去。

如果继续等原来的卖单 100.04 成交，可能等不到。

价格可能先跌。

所以系统可能立刻改成：

```text
100.01 卖出
```

或者：

```text
按卖一价卖出
```

虽然赚得少一点，但能尽快把风险关掉。

结果：

```text
100.00 买入
100.01 卖出
赚 0.01
```

比市场下跌后亏损更安全。

---

# 所以对冲不是为了多赚钱

对冲主要是为了：

```text
不让单边持仓越积越大
不让行情突然反向时爆亏
把做市策略从“赌涨跌”变回“赚价差”
```

---

# 你项目里可以这样理解

简化版不一定要写复杂对冲。

你可以先做：

```text
成交后撤掉旧单
重新报价
根据持仓调整买卖报价
```

例如：

你已经买入很多了：

```text
买单挂远一点
卖单挂近一点
```

让系统更容易卖出减仓。

这也是一种“软对冲”或者库存控制。

真正严格的对冲是：

```text
买成交后立刻卖
卖成交后立刻买
```

但教学版可以先用库存风控代替。
对，这就是做市最核心、也最容易误解的地方。

你已经问到真正关键的问题了：

> “如果每次成交立刻反向对冲，那不是把利润也对掉了吗？”

答案是：

# 做市商不是“每次成交都立刻无脑平仓”

而是：

# “控制库存风险（Inventory Risk）”

---

真正的做市逻辑是：

```text
优先靠自然双边成交赚钱
只有库存风险太大时才主动对冲
```

# 一、理想状态（真正赚钱的状态）

这是做市最舒服的情况：

你挂：

```text
买：100.00
卖：100.04
```

---

先有人卖给你：

```text
你 100.00 买入
```

过一会儿：

又有人买你的卖单：

```text
你 100.04 卖出
```

于是：

```text
100.00 买
100.04 卖
```

你赚：

```text
0.04 spread
```

而且：

```text
仓位回到 0
```

这叫：

# 自然对敲（Natural Inventory Reversion）

这是最理想状态。

做市商最喜欢这个。

---

# 二、问题：市场不会永远平衡

现实中经常：

```text
只成交一边
```

比如：

一直有人卖。

那么：

```text
你的买单疯狂成交
```

你仓位变成：

```text
+1
+2
+5
+10
+20
```

你开始：

# 越来越多头

这时候你已经不是：

```text
做市
```

而是：

```text
被迫做多
```

了。

---

# 三、什么时候真正开始对冲？

通常：

# 当库存偏离太大时

例如：

```text
净持仓 > 10手
```

系统开始：

* 买单挂远
* 卖单挂近
* 主动减仓
* 或直接对冲

---

# 四、所以真正的对冲有很多层级

---

## 第一层：自然成交对冲（最理想）

```text
买单成交
↓
后来卖单也成交
↓
仓位自然回归
```

最好。

赚完整 spread。

---

## 第二层：库存 skew（最常见）

例如：

你已经多头太多。

系统：

```text
买单离市场更远
卖单离市场更近
```

例如：

原来：

```text
买：100.00
卖：100.04
```

变成：

```text
买：99.96
卖：100.02
```

目的：

```text
减少继续买入
增加卖出概率
```

这其实已经是：

# 软对冲

了。

很多真实做市策略主要靠这个。

---

## 第三层：主动对冲（真正强制平仓）

如果市场：

```text
单边暴走
```

你库存越来越大。

系统可能：

```text
直接吃盘口
主动平仓
```

例如：

```text
市价卖出
```

虽然利润少了。

但：

# 保命更重要

---

# 五、你文档里的“成交立即对冲”

其实更像：

# 风控版做市

不是：

# 高频顶级做市

因为教学系统更保守。

它希望：

```text
尽量不要暴露方向风险
```

所以：

```text
成交后立刻对冲
```

# 八、真正一句话总结

你终于碰到做市核心了：

> **做市商不是靠“对冲赚钱”，而是靠“管理库存风险的同时尽量吃到spread赚钱”。**

对冲：

```text
是为了保命
不是为了盈利
```

真正盈利来源永远是：

# spread capture（吃价差）
