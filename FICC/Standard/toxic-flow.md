可以是，但不一定。

“按比例”只是说：

> 每一档的价格偏移，用百分比来表示。

至于这些百分比：

```text
0.01%
0.02%
0.03%
```

是不是等差数列，完全由你自己设定。

---

# 一、等差比例（最常见）

例如：

| 档位  | 偏移     |
| --- | ------ |
| 买1档 | -0.01% |
| 买2档 | -0.02% |
| 买3档 | -0.03% |

基准价：

```text
100
```

那么：

```text
买1档 = 99.99
买2档 = 99.98
买3档 = 99.97
```

这其实和按 tick 很像。

只是：

```text
tick 是固定价格差
比例是固定百分比差
```

---

# 二、也可以不是等差

比如：

| 档位  | 偏移     |
| --- | ------ |
| 买1档 | -0.01% |
| 买2档 | -0.03% |
| 买3档 | -0.08% |

这叫：

# 非线性铺价

什么意思？

离市场越远：

* 挂得越稀疏
* spread 拉得越大

这是很多真实做市策略会干的。

---

# 三、为什么会这样？

因为：

## 靠近 mid 的位置：

成交概率高。

但：

```text
容易被毒流（toxic flow）打穿
```

---

## 离得远：

成交概率低。

但：

```text
更安全
```

所以很多机构会：

```text
内层密
外层疏
```

---

# 四、最真实的机构铺价其实不是等差

而是：

# Inventory-aware quoting

例如：

如果你：

```text
已经买了很多仓位
```

系统会：

* 买单挂远一点
* 卖单挂近一点

迫使市场帮你减仓。

这已经进入：

# inventory skew

领域了。

---

# 五、你项目建议

你现在：

# 直接用等差就行

例如：

```text
买1档：-1 tick
买2档：-2 tick
买3档：-3 tick

卖1档：+1 tick
卖2档：+2 tick
卖3档：+3 tick
```

最稳定。

最容易实现。

最适合报告。
