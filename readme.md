## 📂 目录结构说明

### 1. [FICC (固定收益、外汇及商品)](file:///c:/Users/ultra/Desktop/面试/FICC/)

- **数据库设计**: 完整的迁移脚本 (Migrations) 涵盖了资产、交易历史、订单簿等表结构。

本项目旨在通过结合**金融业务理解**与**技术实现能力**，展示在金融科技领域的综合竞争力：
1. **深度业务洞察**: 理解 FICC 等复杂金融业务的运作机制。
2. **全栈开发能力**: 从数据库设计到 Web3 接口集成的完整后端开发。
3. **前沿技术应用**: 探索 AI (RAG) 与量化策略在金融场景下的落地。
